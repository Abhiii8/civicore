## 🚀 Quick Start

### Viewing PlantUML Diagrams

1. **Online Viewer**:
   - Visit: http://www.plantuml.com/plantuml/uml/
   - Copy content from `.puml` files
   - Paste and view

2. **VS Code Extension**:
   - Install "PlantUML" extension
   - Open `.puml` files
   - Preview with Ctrl+Shift+P → "PlantUML: Preview"

3. **Desktop Tool**:
   - Download PlantUML from http://plantuml.com/
   - Use with Graphviz

### Viewing Markdown Files

- Use any markdown viewer (VS Code, GitHub, etc.)
- Or convert to PDF using tools like Pandoc

### Database Schema

- Import `database_schema.sql` into MySQL:
  ```bash
  mysql -u root -p < database_schema.sql
  ```
